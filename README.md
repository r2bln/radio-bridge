# radio-bridge

Удалённый доступ к аналоговой УКВ-станции через браузер: слушать приём и передавать
голос кнопкой PTT. Станция подключена к Linux-хосту через звуковую карту (USB-переходник
или гарнитурный разъём ноутбука), в эфир выходит по VOX — отдельной PTT-линии нет.

```
браузер (PTT, колонки, микрофон)  ──wss / tailnet──►  radio-bridge  ──audio──►  станция (VOX)
```

- Сервер — Python (`aiohttp`), клиент — статическая страница, которую отдаёт сервер.
- Звук — G.711 μ-law 8 кГц по WebSocket, приём отправляется только при открытом шумодаве.
- Безопасность эфира: ограничение времени передачи (TOT), автоотпускание при обрыве связи,
  на выход звуковой карты не попадает ничего, кроме осознанной передачи.

**Статус:** спецификация, кода ещё нет. Подробности — [`docs/SPEC.md`](docs/SPEC.md).
