# radio-bridge

Удалённый доступ к аналоговой УКВ-станции через браузер: слушать приём и передавать
голос кнопкой PTT. Станция подключена к Linux-хосту через звуковую карту (USB-переходник
или гарнитурный разъём ноутбука), в эфир выходит по VOX — отдельной PTT-линии нет.

```
браузер (PTT, колонки, микрофон)  ──wss / tailnet──►  radio-bridge  ──audio──►  станция (VOX)
```

- Сервер — Python (`aiohttp`), клиент — статическая страница, которую отдаёт сервер.
- Звук — G.711 μ-law 8 кГц по WebSocket, приём отправляется только при открытом шумодаве.
- Безопасность эфира: ограничение времени передачи (TOT), автоотпускание при обрыве связи,
  на выход звуковой карты не попадает ничего, кроме осознанной передачи.

Спецификация — [`docs/SPEC.md`](docs/SPEC.md).

## Статус

**v0.2** — сервер, веб-клиент, фейковое аудиоустройство, тесты. Проверено вживую на
тестовом хосте `tvbox` (2026-10-18): приём слышен в браузере, тон будит VOX, голос
выходит в эфир. Дальше — v0.3: USB-звуковуха и деплой на дачный хост через `infra`.

Запуск на tvbox — [`dev/tvbox.sh`](dev/tvbox.sh) `start [dry] | stop | status | log`.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/python -m pytest -q

# без железа: синтетический приём, передача пишется в data/tx-*.wav
AUDIO_DEVICE=fake .venv/bin/python -m radio_bridge
# → https://<хост>:8443  (сертификат самоподписанный, создаётся в data/)
```

Основные переменные (полный список — SPEC §9):

| Переменная | По умолчанию | |
|---|---|---|
| `AUDIO_DEVICE` | `fake` | `fake`, `fake:<wav 8 кГц моно>`, `sd:<устройство>` или `sd:<вход>,<выход>` (`python -m sounddevice` — список) |
| `LISTEN` | `0.0.0.0:8443` | |
| `TLS` | `1` | `0` — голый http (микрофон в браузере тогда работает только на `localhost`) |
| `TLS_SAN` | имя хоста, localhost | имена/IP для сертификата через запятую |
| `DATA_DIR` | `data` | сертификат и WAV-записи |
| `TX_TOT_S` | `180` | |
| `TX_DRY_RUN` | `0` | `1` — на реальном устройстве выход = тишина, передача в WAV |
| `RX_GATE_DB` | `-45` | порог гейта приёма, dBFS |
| `VOX_TONE_HZ` / `_MS` / `_DBFS` | `1000` / `500` / `-12` | тон, будящий VOX |

> ⚠ Клиент воспроизводит приём на устройство вывода браузера. Если на той же машине
> выход подключён к передатчику — приём уйдёт обратно в эфир. Открывайте клиент на
> устройстве, не подключённом к рации.
